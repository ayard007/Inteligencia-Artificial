Espacio de estados

</> Paso 2 — Construir el grafo

De texto a grafo

Esta función recorre el laberinto y construye el grafo: a cada casilla libre le asocia sus vecinas sin muros. Esas vecinas son los operadores: los movimientos posibles.

# ------------------------------------------------------------
# PASO 2 - CONSTRUIR EL GRAFO (nodos y aristas)
# ------------------------------------------------------------
def construir_grafo(mapa):
    grafo = {}
    for r in range(len(mapa)):
        for c in range(len(mapa[0])):
            if mapa[r][c] != "#":                 # casilla libre = estado
                vecinos = []
                for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:   # operadores
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < len(mapa) and 0 <= nc < len(mapa[0]) and mapa[nr][nc] != "#":
                        vecinos.append((nr, nc))
                grafo[(r, c)] = vecinos
    return grafo

def buscar_simbolo(mapa, simbolo):
    return [(r, c) for r in range(len(mapa)) for c in range(len(mapa[0])) if mapa[r][c] == simbolo]

Conecta con el código

La lista [(-1,0),(1,0),(0,-1),(0,1)] son los cuatro movimientos. El grafo es lo que usarán BFS y A*.

</> Paso 3 — Búsquedas BFS y A* (Semanas 9 y 10)

Cómo encuentran el camino los fantasmas

Aquí están los dos algoritmos. BFS usa una cola y explora por niveles. A* usa una cola de prioridad y una heurística (manhattan) para dirigirse al jugador explorando menos.

# ------------------------------------------------------------
# PASO 3 - BUSQUEDAS: BFS (S9) y A* (S10)
# ------------------------------------------------------------
def manhattan(a, b):
    return abs(a[0] - b[0]) + abs(a[1] - b[1])   # heuristica para A*

def bfs(grafo, inicio, meta):
    frontera = deque([[inicio]])      # cola de caminos (FIFO)
    visitados = set()
    while frontera:
        camino = frontera.popleft()
        nodo = camino[-1]
        if nodo == meta:
            return camino
        if nodo not in visitados:
            visitados.add(nodo)
            for v in grafo[nodo]:
                frontera.append(camino + [v])
    return None

def a_estrella(grafo, inicio, meta):
    abierta = [(0, inicio, [inicio])]   # cola de prioridad por f = g + h
    visitados = set()
    while abierta:
        f, nodo, camino = heapq.heappop(abierta)
        if nodo == meta:
            return camino
        if nodo in visitados:
            continue
        visitados.add(nodo)
        for v in grafo[nodo]:
            g = len(camino)
            h = manhattan(v, meta)
            heapq.heappush(abierta, (g + h, v, camino + [v]))
    return None

Conecta con el código

La función manhattan es la pista de A*. Si la cambiaras para que devuelva 0, A* se comportaría igual que BFS.

</> Paso 4 — La IA de los fantasmas (Semana 8)

Determinístico vs no determinístico

Esta función decide el paso de cada fantasma. Con probabilidad distraccion se mueve al azar (no determinístico); si no, persigue con su algoritmo (determinístico).

# ------------------------------------------------------------
# PASO 4 - IA DE LOS FANTASMAS (determinista vs no determinista, S8)
# ------------------------------------------------------------
def paso_fantasma(grafo, pos_fantasma, pos_jugador, metodo="astar", distraccion=0.2):
    # con probabilidad 'distraccion' se mueve al azar (no determinista)
    if random.random() < distraccion:
        return random.choice(grafo[pos_fantasma])
    # si no, persigue con su algoritmo (determinista)
    camino = a_estrella(grafo, pos_fantasma, pos_jugador) if metodo == "astar" \
        else bfs(grafo, pos_fantasma, pos_jugador)
    if camino and len(camino) > 1:
        return camino[1]
    return pos_fantasma

Conecta con el código

Un fantasma con distraccion=0 es imposible de esquivar; con distraccion=1 se mueve al azar. Equilibrar ese valor es parte de tu entregable.

</> Paso 5 — Las monedas con CSP (Semana 11)

Satisfacción de restricciones

Las monedas se colocan respetando restricciones: no sobre el jugador ni los fantasmas, y separadas al menos separacion casillas. Eso es un CSP.

# ------------------------------------------------------------
# PASO 5 - MONEDAS CON CSP (restricciones, Semana 11)
# ------------------------------------------------------------
def colocar_monedas(grafo, jugador, fantasmas, cantidad=8, separacion=2):
    libres = [p for p in grafo if p != jugador and p not in fantasmas]
    random.shuffle(libres)
    monedas = []
    for p in libres:
        if all(manhattan(p, m) >= separacion for m in monedas):   # restriccion
            monedas.append(p)
        if len(monedas) == cantidad:
            break
    return set(monedas)

Conecta con el código

Si subes mucho separacion, quizá no quepan todas: el problema se vuelve insatisfacible, un concepto clave de los CSP.

</> Paso 6 — El jugador Minimax (Semana 11)

Teoría de juegos y multiagente

Un jugador automático que decide con la idea de Minimax: elige el movimiento que lo deja más lejos del fantasma más cercano y más cerca de una moneda.

# ------------------------------------------------------------
# PASO 6 - JUGADOR AUTOMATICO MINIMAX (teoria de juegos, Semana 11)
# ------------------------------------------------------------
def jugador_minimax(grafo, pos_jugador, fantasmas, monedas):
    mejor_mov, mejor_valor = pos_jugador, -9999
    for mov in grafo[pos_jugador]:
        seguridad = min(manhattan(mov, f) for f in fantasmas)   # MAX: alejarse
        cerca_moneda = -min((manhattan(mov, m) for m in monedas), default=0)
        valor = seguridad * 2 + cerca_moneda
        if valor > mejor_valor:
            mejor_valor, mejor_mov = valor, mov
    return mejor_mov

Conecta con el código

Es un entorno multiagente: anticipa que los fantasmas se acercarán. Tu reto será que mire dos pasos adelante.

CONFIG_FANTASMAS = [

NUM_MONEDAS = 8
SEPARACION_MONEDAS = 2

</> Paso 8 — El bucle principal del juego

Donde todo se une

La función main arranca pygame, crea la ventana y ejecuta el bucle del juego: lee el teclado, mueve al jugador y a los fantasmas, revisa colisiones y victoria, y vuelve a dibujar.

# ------------------------------------------------------------
# PASO 8 - DIBUJO CON PYGAME
# ------------------------------------------------------------
def dibujar(pantalla, fuente, jugador, fantasmas, monedas, puntos, vidas, nivel, mensaje):
    pantalla.fill(COLOR_FONDO)
    # muros y pasillos
    for r in range(FILAS):
        for c in range(COLS):
            x, y = c * CELDA, r * CELDA
            color = COLOR_MURO if MAPA[r][c] == "#" else COLOR_PASILLO
            pygame.draw.rect(pantalla, color, (x, y, CELDA, CELDA))
            if MAPA[r][c] != "#":
                pygame.draw.rect(pantalla, COLOR_FONDO, (x, y, CELDA, CELDA), 1)
    # monedas
    for (r, c) in monedas:
        cx, cy = c * CELDA + CELDA // 2, r * CELDA + CELDA // 2
        pygame.draw.circle(pantalla, COLOR_MONEDA, (cx, cy), CELDA // 6)
    # fantasmas
    colores_f = [COLOR_F1, COLOR_F2, (255, 140, 0)]
    for i, (r, c) in enumerate(fantasmas):
        cx, cy = c * CELDA + CELDA // 2, r * CELDA + CELDA // 2
        pygame.draw.circle(pantalla, colores_f[i % 3], (cx, cy), CELDA // 2 - 4)
    # jugador
    jr, jc = jugador
    pygame.draw.circle(pantalla, COLOR_JUGADOR, (jc * CELDA + CELDA // 2, jr * CELDA + CELDA // 2), CELDA // 2 - 4)
    # HUD (marcador)
    hud_y = FILAS * CELDA + 10
    texto = "Puntos: {}    Monedas restantes: {}    Vidas: {}    Nivel: {}".format(
        puntos, len(monedas), vidas, nivel)
    pantalla.blit(fuente.render(texto, True, COLOR_TEXTO), (12, hud_y))
    if mensaje:
        pantalla.blit(fuente.render(mensaje, True, COLOR_MONEDA), (12, hud_y + 28))
    pygame.display.flip()

# ------------------------------------------------------------
# PASO 9 - BUCLE PRINCIPAL DEL JUEGO
# ------------------------------------------------------------
def main():
    pygame.init()
    pantalla = pygame.display.set_mode((ANCHO, ALTO))
    pygame.display.set_caption("Laberinto Inteligente - UNE")
    fuente = pygame.font.SysFont("consolas", 20)
    reloj = pygame.time.Clock()

    grafo = construir_grafo(MAPA)
    inicio_jugador = buscar_simbolo(MAPA, "J")[0]
    inicio_fantasmas = buscar_simbolo(MAPA, "G") + buscar_simbolo(MAPA, "F")

    jugador = inicio_jugador
    fantasmas = list(inicio_fantasmas)
    monedas = colocar_monedas(grafo, jugador, fantasmas, NUM_MONEDAS, SEPARACION_MONEDAS)
    puntos, vidas, nivel = 0, VIDAS_INICIALES, 1
    mensaje = "Flechas o WASD para moverte.  I = modo IA.  R = reiniciar."
    modo_ia = False
    terminado = False

    def un_turno(direccion):
        nonlocal jugador, fantasmas, monedas, puntos, vidas, mensaje, terminado
        # mover jugador
        dr, dc = {"arriba": (-1, 0), "abajo": (1, 0), "izq": (0, -1), "der": (0, 1)}.get(direccion, (0, 0))
        destino = (jugador[0] + dr, jugador[1] + dc)
        if destino in grafo:
            jugador = destino
        # recoger moneda
        if jugador in monedas:
            monedas.discard(jugador)
            puntos += 1
        # mover fantasmas
        nuevos = []
        for i, f in enumerate(fantasmas):
            metodo, distra = CONFIG_FANTASMAS[i % len(CONFIG_FANTASMAS)]
            nuevos.append(paso_fantasma(grafo, f, jugador, metodo, distra))
        fantasmas = nuevos
        # colision
        if jugador in fantasmas:
            vidas -= 1
            jugador = inicio_jugador
            if vidas <= 0:
                mensaje = "PERDISTE: sin vidas. Pulsa R para reiniciar."
                terminado = True
        # victoria
        if not monedas and not terminado:
            mensaje = "GANASTE! Recogiste todas las monedas. Pulsa R."
            terminado = True

    ia_contador = 0
    jugando = True
    while jugando:
        for evento in pygame.event.get():
            if evento.type == pygame.QUIT:
                jugando = False
            elif evento.type == pygame.KEYDOWN:
                if evento.key == pygame.K_r:
                    # reiniciar
                    jugador = inicio_jugador
                    fantasmas = list(inicio_fantasmas)
                    monedas = colocar_monedas(grafo, jugador, fantasmas, NUM_MONEDAS, SEPARACION_MONEDAS)
                    puntos, vidas = 0, VIDAS_INICIALES
                    mensaje = "Juego reiniciado."
                    terminado = False
                elif evento.key == pygame.K_i:
                    modo_ia = not modo_ia
                    mensaje = "Modo IA " + ("ACTIVADO" if modo_ia else "DESACTIVADO")
                elif not terminado and not modo_ia:
                    if evento.key in (pygame.K_UP, pygame.K_w):
                        un_turno("arriba")
                    elif evento.key in (pygame.K_DOWN, pygame.K_s):
                        un_turno("abajo")
                    elif evento.key in (pygame.K_LEFT, pygame.K_a):
                        un_turno("izq")
                    elif evento.key in (pygame.K_RIGHT, pygame.K_d):
                        un_turno("der")

        # modo IA: el jugador se mueve solo cada ciertos cuadros
        if modo_ia and not terminado:
            ia_contador += 1
            if ia_contador >= 15:   # ~4 movimientos por segundo
                ia_contador = 0
                destino = jugador_minimax(grafo, jugador, fantasmas, monedas)
                dr, dc = destino[0] - jugador[0], destino[1] - jugador[1]
                direccion = {(-1, 0): "arriba", (1, 0): "abajo", (0, -1): "izq", (0, 1): "der"}.get((dr, dc), "")
                un_turno(direccion)

        dibujar(pantalla, fuente, jugador, fantasmas, monedas, puntos, vidas, nivel, mensaje)
        reloj.tick(60)

    pygame.quit()

# ------------------------------------------------------------
# Punto de entrada: esto es lo que ejecuta VS Code al correr el archivo
# ------------------------------------------------------------
if __name__ == "__main__":
    main()

Nota importante sobre "aprender". Los fantasmas de este juego no aprenden con el tiempo como una red neuronal: deciden en cada turno aplicando un algoritmo de búsqueda. Experimento 4 — Haz que la IA se adapte (dificultad dinámica)

En el Paso 4, haz que el fantasma persiga con más fuerza cuando está lejos y se relaje cuando está cerca. Así la IA reacciona mejor al estado del juego.

def paso_fantasma(grafo, pos_fantasma, pos_jugador, metodo="astar", distraccion=0.2):
    # dificultad dinamica: si esta lejos, persigue mas (menos distraccion)
    d = manhattan(pos_fantasma, pos_jugador)
    if d > 6:
        distraccion = 0.05   # lejos: casi siempre persigue
    if random.random() < distraccion:
        return random.choice(grafo[pos_fantasma])
    camino = a_estrella(grafo, pos_fantasma, pos_jugador) if metodo == "astar" \
        else bfs(grafo, pos_fantasma, pos_jugador)
    if camino and len(camino) > 1:
        return camino[1]
    return pos_fantasma

Qué debes identificar
